# 모델 학습 진행 상황 (26.08.01)

## 현재 정확도

서초구 4월 한 달치(938만 행) 데이터로 학습한 결과, **모델A(입석여부) AUC 0.9447, Accuracy 93.1%**, **모델B(입석시간) 평균 오차 121초(약 2분)** 수준입니다.

## 300트리 → 1000트리, 트리 수를 늘리며 확인한 개선 추이

| | 300트리 | 1000트리 | 개선 |
| --- | --- | --- | --- |
| 모델A AUC | 0.9374 | **0.9447** | ↑ |
| 모델A Accuracy | 92.84% | **93.07%** | ↑ |
| 모델B MAE | 127.2초 | **121.4초** | ↓ (오차 감소) |
| 모델B RMSE | 186.5초 | **178.7초** | ↓ (오차 감소) |

트리 수를 늘렸더니 전 지표가 개선됐고, 아직 `early stopping`이 걸리지 않고 있어 — 즉 1000번째 트리까지도 성능이 계속 좋아지는 중이었습니다. 더 늘리면 추가 개선 여지가 남아있다는 뜻이라, 다음 실험에서 트리 수를 더 키워보거나 다른 하이퍼파라미터(학습률 등)를 조정해가며 성능을 더 끌어올릴 계획입니다.

## 그 외 확인된 내용

- 피처 중요도 기준, 승차/하차 정류장이 예측에 압도적으로 중요했고 노선·시각이 다음, 공휴일·좌석수는 기여도가 거의 없었습니다 (4월 데이터에 공휴일이 없어서 나타난 현상으로 추정 — 다른 달 데이터가 오면 재확인 필요)
- 실험은 `wandb`로 추적 중이라, 트리 수/학습률 등을 바꿔가며 실험할 때마다 성능 변화를 그래프로 비교할 수 있는 환경을 갖춰뒀습니다. 프로젝트 링크: `https://wandb.ai/newhaneul-inha-university/bus-standing-prediction`
- 실험 결과 원본(로그, 모델 파일, metrics.json)은 `experiments/26.08.01.17-18-00/`에서 확인 가능합니다
