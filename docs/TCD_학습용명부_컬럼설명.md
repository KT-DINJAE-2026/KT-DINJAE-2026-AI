# TCD 학습용 승객 명부 — 컬럼 설명

`TCD_학습용명부_예시스펙.parquet` 파일의 컬럼별 정의입니다. 백엔드에 요청할 학습용 명부 스펙 예시로, 실제 데이터가 아닌 필드명·구조 확인용 목업입니다.

한 행 = 승객 1명의 1회 탑승 기준입니다.

## 컬럼 정의

| # | 열 이름 | 의미 | 구분 |
| --- | --- | --- | --- |
| 1 | `trip_round_id` | 운행회차 식별자 (차량ID + 운행출발일시 조합) — 같은 차량이 하루에 여러 번 도는 걸 구분 | 식별 키 |
| 2 | `route_id` | 노선 ID (국토부 표준) | 식별 키 |
| 3 | `board_stop_id` | 승차 정류장 ID (국토부 표준) | 식별 키 |
| 4 | `alight_stop_id` | 하차 정류장 ID (국토부 표준) | 식별 키 |
| 5 | `board_datetime` | 승차 일시 | 입력 피처 |
| 6 | `weekday` | 요일 | 입력 피처 |
| 7 | `hour` | 승차 시각(시 단위) | 입력 피처 |
| 8 | `is_holiday` | 공휴일 여부(True/False) | 입력 피처 |
| 9 | `weather` | 승차 시점 날씨 | 입력 피처 |
| 10 | `headway_sec` | 배차간격(초) — 같은 노선·정류장에서 앞뒤 차량 도착 간격 | 입력 피처 |
| 11 | `bus_type_code` | 버스 유형 코드 (105=마을, 115=간선, 120/121/122=지선) | 입력 피처 |
| 12 | `bus_type_name` | 버스 유형 이름 (마을버스/간선버스/지선버스) | 입력 피처 |
| 13 | `seat_capacity` | 버스 유형별 좌석수 (마을 20석, 간선·지선 25석) | 입력 피처 |
| 14 | `usertype_code` | 사용자구분코드 (01=일반인, 04=경로, 05=장애인 등) | 입력 피처 |
| 15 | `usertype_name` | 사용자구분 이름 | 입력 피처 |
| 16 | `is_standing` | 정답 레이블 — 입석 여부 (Y/N) | 정답 레이블 |
| 17 | `standing_seconds` | 정답 레이블 — 입석 지속 시간(초), 입석 없으면 0 | 정답 레이블 |
| 18 | `sample_count_route_segment_hour` | 해당 (노선, 구간, 시간대) 조합의 학습 표본 수 — `INSUFFICIENT_DATA` 판정용 | 보조 정보 |

## 구조 요약

- **1~4번**: 이 탑승이 언제/어느 차/어느 구간인지 식별하는 키 값
- **5~15번**: 모델 학습 입력 피처
- **16, 17번**: 모델이 맞혀야 할 정답 레이블 (백엔드가 재차인원·FIFO 시뮬레이션으로 산출)
- **18번**: 데이터 신뢰도/부족 여부 판단용 보조 정보

레이블(16, 17번) 산출 방식과 백엔드 요청 사항은 `TCD_meeting_notes_20260722.md`의 "3. 백엔드에 요청할 사항" 참고.
